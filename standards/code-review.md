# 코드 리뷰 체크리스트

AI 에이전트의 자기 리뷰 및 사람 리뷰에 공통으로 사용한다.

## 정확성

- [ ] 요구사항을 모두 충족하는가 (누락·초과 구현 없음)
- [ ] 엣지 케이스(빈 값·비활성·에러)를 처리하는가

## 표준 준수

- [ ] `component-authoring.md` 준수 (props 타입 명시, `any` 없음)
- [ ] 접근성 (시맨틱 태그·role·label)
- [ ] 테스트 동반 & `npm test` 통과 (`testing.md`)

## 품질

- [ ] 불필요한 복잡도·중복 없음 (DRY, YAGNI)
- [ ] 네이밍이 의도를 드러내는가
- [ ] 부수효과가 적절히 분리되어 있는가
