# 프롬프트: 테스트 생성·보강

---

`standards/testing.md`를 먼저 읽어라.

대상: `{{파일 경로}}`

이 컴포넌트의 테스트를 사용자 관점(Testing Library, role·label 쿼리)으로 작성/보강하라.
다음을 커버한다:

- 렌더링 — 필수 콘텐츠·역할
- 상호작용 — `{{이벤트}}` 시 콜백/상태 변화
- 분기 — `{{variant/조건}}`별 동작
- 엣지 — 빈 값·비활성·에러 경로

구현 세부(클래스명·내부 상태)에 의존하지 말 것. 커버리지 80% 이상을 목표로 한다.
작성 후 `npm test`로 통과를 확인하고 결과를 요약하라.
