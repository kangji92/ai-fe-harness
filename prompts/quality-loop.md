# 프롬프트: 품질 루프 (정적 분석 → AI 개선 → 재검증)

SonarQube · ESLint 등의 리포트를 AI 개선 사이클로 연결한다.

---

아래는 정적 분석 리포트다:

```
{{SonarQube / ESLint 리포트 붙여넣기 — 규칙 ID, 파일, 라인, 메시지}}
```

절차:

1. 각 지적을 **심각도·유형별로 분류**한다 (버그 / 코드 스멜 / 취약점 / 스타일).
2. `standards/`를 기준으로 **표준에 부합하는 개선안**을 제시한다.
   - 표준과 충돌하는 지적은 그대로 반영하지 말고 근거와 함께 표시한다.
3. 개선을 적용한다 (동작을 바꾸지 않는 범위에서).
4. `npm test` · `npm run typecheck`로 **회귀가 없음을 검증**한다.
5. 무엇을 왜 바꿨는지 커밋 컨벤션에 맞춰 요약한다.

목표: "리포트 → 개선 → 재검증"을 사람 개입 최소로 반복 가능한 루프로 만든다.
